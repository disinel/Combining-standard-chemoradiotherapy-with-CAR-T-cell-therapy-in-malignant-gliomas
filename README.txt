
**README**

Code repository accompanying Dmitry Sinelschikov, Nikols Amaru Mora Millán, Miguel Perales-Patón, Juan Belmonte-Beitia, Matteo Italia.
Combining standard chemoradiotherapy with CAR-T cell therapy in malignant
gliomas: Insights from an impulsive mathematical framework and virtual trials. (manuscript submitted for review, 2026).

This repository contains the codes developed in Matlab to simulate the interactions between sensitive, resistance to TMZ, resistance to CAR-T therapy tumor cells,  CAR-T cells, TMZ drug and radio therapy applied to malignant gliomas, a fatal tumor brain.
